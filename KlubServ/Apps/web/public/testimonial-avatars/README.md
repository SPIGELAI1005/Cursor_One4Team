## Image Specifications

- **Format**: JPG
- **Size**: 200x200 pixels minimum (will be displayed at 48x48px)
- **Style**: Professional headshots with good lighting
- **Background**: Clean, professional backgrounds
- **Quality**: High resolution for crisp display

## Fallback

If images are not available, the system will automatically fall back to displaying initials in a circular avatar.
